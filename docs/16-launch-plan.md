# 16 — Launch Plan (план запуска)

**Связано:** [05](05-mvp-scope.md) · [17](17-growth-strategy.md) · [18](18-metrics.md) · [22](22-execution-order.md)

Не запускать рекламу на пустую витрину. Числовые KPI: `TBD — establish baseline during beta`, метод — зафиксировать фактические значения за 2 недели беты и назначить цели второй итерации.

## Phase 0 — Discovery (исследование)

**Objective:** подтвердить боль и каналы, не писать продукт вслепую.

**Tasks:**

- Интервью по [03](03-personas-jtbd.md).
- Аудит конкурентов по чеклисту [02](02-market-research.md).
- Concierge: таблица объявлений + Telegram-канал вручную (опционально, дёшево).
- Закрыть D-02, D-05 хотя бы как план.
- Собрать список 20–40 салонов/организаторов для seed.

**KPI:** число интервью; качественные цитаты; решение go / pivot / stop.

**Exit criteria:** ≥8 интервью; письменный вывод «боль жива / не жива»; если не жива — не строить P0.

**Stop:** мастера стабильно закрывают кабинет за день на Avito и не ходят на МК через чаты — пересмотреть фокус (только события или не делать).

## Phase 1 — Seed (формирование начального предложения)

**Objective:** на витрине есть **чужие реальные** объявления, не демо-lorem.

### Seed Strategy

Не цель «100–200 объектов» из исходника — нет основания.

**Метод установления N:** после 10 договорённостей оценить, сколько карточек реально дадут за 2 недели. Baseline = факт.

**Как вручную получить:**

**Мастера (спрос, не витрина профилей):** не гнать регистрации без кабинетов. Приглашать смотреть канал, когда есть 10+ карточек.

**Помещения / салоны:**

> Запускаем площадку для мастеров Ростова. Если есть свободный кабинет — разместим бесплатно и приведём мастеров из профессионального контура.

Обход  (не выдумывать 50–100 как обязаловку): начать с 10 адресов из Яндекс.Карт / знакомых. Фиксировать отказы.

**Мероприятия:** организаторы МК — обмен: анонс у них в сторис ↔ карточка у нас. Цель — даты в ближайшие 30 дней, иначе события «мертвые».

**Салоны как вакансии:** «ищу мастера» параллельно с кабинетом.

**KPI:** обещанные карточки vs опубликованные; разнообразие типов (не только один салон).

**Exit criteria:** ≥15 реальных карточек, покрывающие хотя бы 2 типа (кабинеты + события **или** кабинеты + вакансии). Если только вакансии — гипотеза кабинетов не проверена.

Операционная нагрузка: Community/основатель, не инженер.

## Phase 2 — Closed Beta (закрытая бета-версия)

**Objective:** реальные пользователи на работающем P0, сбор метрик, баги.

**Tasks:** собрать 20–50 человек не «всех подряд»: те, кто в интервью дал контакт + авторы seed. Модератор в часах D-05. Аналитика включена. Staging проверен.

**KPI:** `listing_viewed`, `contact_clicked`, `telegram_connected`, reports, качественный фидбек. Числа целей TBD после первой недели (метод: медиана недельных значений).

**Exit criteria:**

- Критические CUJ не ломаются.
- Есть ≥1 подтверждённый (ручной) успешный контакт **или** устойчивый прокси + объяснение почему без подтверждения (честно).
- Список изменений UX.

**Не exit:** «всем нравится идея».

---

## Phase 3 — Public Launch (публичный запуск)

**Objective:** открытый сайт + канал для Ростова.

**Tasks:** юридические страницы; прод-бот; пост в канале; точечные партнёры (магазины, салоны); **не** широкая закупка до удержания беты.

**KPI:** WAU TBD; новые listing/нед TBD; отписки бота как guardrail.

**Exit criteria:** процесс модерации выдерживает поток; нет критичных инцидентов безопасности.

## Phase 4 — Growth (рост)

См. [17](17-growth-strategy.md). Matching v1 по сигналу. Второй город — не эта фаза.

**Exit:** не применимо (ongoing). Критерий **остановить рост-траты:** нет соединений при росте регистраций.

## Роли на запуске

| Роль | Фаза |
| --- | --- |
| Product | 0–4 приоритеты |
| Community | seed, канал, модерация контента |
| Tech | 2–3 стабильность |
| Модератор | 2–4 очередь pending |

Если один человек — не запускать Phase 3, пока очередь pending не укладывается в обещанный SLA (даже если SLA = «раз в день вечером», его надо написать в UI честно).
