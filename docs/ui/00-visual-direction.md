# 00 — Visual Direction (визуальное направление)

**Этап:** U1 Visual UI Design  
**Канон:** [../24-implementation-spec.md](../24-implementation-spec.md) §3.1–3.3 · [../ux/10-design-system.md](../ux/10-design-system.md)  
**Не код.** Нет Figma в репозитории — это спецификация для последующих макетов 375 / 1280.

Не меняем MVP, потоки и функции U0.

---

## 1. Visual personality (характер)

Beauty Hub выглядит как **рабочий стол мастера в городе**: спокойная бумага, чёткая сетка, один акцентный жест на действие. Не витрина бренда и не лента.

Ощущение: современный, быстрый, плотный достаточно для сканирования карточек, без «воздуха лендинга».

Антиреференсы (не копировать):

| Не быть | Почему |
| --- | --- |
| Instagram | нет stories, градиентов, кружков аватаров в ленте |
| Avito | нет горизонтальных «рядов объявлений», жёлтого CTA, перегруза фильтров |
| LinkedIn | нет синей корпоративности и карьеры как соцсеть |
| Telegram | веб не клонирует пузыри чата |
| Generic SaaS | нет холодного серо-синего дашборда и графиков на Home |
| Beauty landing | нет розового глянца, золота, скриптов «роскошь» |

---

## 2. Brand character (характер бренда)

Словомарка: **Beauty Hub** — два слова, без слогана в шапке. Подпись города «Ростов-на-Дону» только на Home, muted.

Голос визуала: нейтральное «вы», короткие подписи, бейджи с буквами, не стикеры.

---

## 3. Color philosophy (цвет)

- Фон — тёплый светлый камень (не чисто белый стерильный SaaS и не крем «spa»).
- Поверхности карточек — чуть светлее/чище фона, отделение **бордером**, не тенью-облаком.
- Текст — почти чернила, не серый 40%.
- **Один accent:** глубокий оксидированный teal (зелёно-синий), как инструмент, не как «кнопка маркетплейса».
- Статусы (pending/reject) — отдельные semantic, не второй бренд-цвет.
- Бейджи типов **не радуга**: одна нейтральная плашка + подпись; различие текстом.

Контраст body к фону ≥ 4.5:1.

Конкретные значения: [01-ui-foundation.md](01-ui-foundation.md).

---

## 4. Typography direction (шрифт)

Одно семейство гротеск, геометрически спокойный, кириллица полная.

**Рекомендация для макетов:** Manrope (Regular / Medium / SemiBold / Bold). Альтернатива с той же ролью: PT Root UI или Inter — если Manrope недоступен, не смешивать два гротеска на экране.

Иерархия только size + weight. Заголовки не в serif (это не журнал). Числа цены — tabular lining, если доступны.

---

## 5. Spacing (ритм)

Сетка **8**. Экран mobile: поля 16. Между карточками 12. Внутри карточки 12 вертикально после фото, горизонталь 12.

Плотность: **medium-high** — больше карточек на экран, чем у лендинга; меньше, чем у Excel-админки публичной части. Админка — ещё плотнее.

---

## 6. Border radius (скругления)

- Карточка, инпут, чип: **10**
- Кнопка: **10**
- Sheet сверху: **16**
- Бейдж типа: **6** (чуть квадратнее, чтобы не pill-соцсеть)
- Аватар автора на details: **8** (не круг Instagram)

Не 999px pills на карточках.

---

## 7. Shadows (тени)

По умолчанию **нет тени** у карточки в списке — только `border`.

Допустимы:

- sheet / dialog: мягкая тень вверх (`elevation.sheet`);
- pressed не «вдавливать» карточку тенью.

---

## 8. Surfaces (поверхности)

| Поверхность | Применение |
| --- | --- |
| `bg` | страница, зазоры |
| `surface` | карточка, шапка, таббар, поля |
| `surfaceMuted` | плашка без фото, skeleton, админ-строка |
| Overlay | 40% чернил на sheet backdrop |

Таббар и шапка — `surface` + верхняя/нижняя hairline border, не blur-glass (тренд ради тренда).

---

## 9. Iconography (иконки)

Линейные, 1.75–2px stroke, rounded caps, размер 20/24 в таббаре. Не filled-дуотон. Не emoji в UI.

Таббар: дом, лупа, плюс в квадрате 10 radius, человек. Бейдж типа — **текст**, иконка необязательна; если есть — простые: квадрат (кабинет), календарь (событие), бейдж (вакансия).

---

## 10. Button style (кнопки)

Primary: заливка accent, текст accentText, без градиента, высота 48 mobile / 44 desktop.  
Secondary: поверхность + border.  
Danger: outline danger или заливка danger только на confirm.

Одна primary на смысловой экран.

---

## 11. Input style (поля)

Лейбл 13 muted над полем. Поле высота 48, border 1, radius 10, фон surface. Фокус: border accent 2px, без glow. Ошибка: border danger + текст 13 под полем.

Placeholder не заменяет лейбл.

---

## 12. Card style (карточки)

Вертикальный блок: фото 4:3 → паддинг 12 → мета. Вся карточка = одна цель нажатия. Hairline border. Не hover-lift на mobile. Desktop hover: border чуть темнее, без scale.

---

## 13. Badges (бейджи)

Тип: высота 22, padding 6×8, фон `surfaceMuted`, текст 12 Medium, цвет text.  
Статус: те же размеры, semantic bg очень светлый + текст semantic (не кислотный).

---

## 14. Navigation (навигация)

Mobile: нижний таббар 56 + safe area, 4 слота, подписи 11. Активный: accent на иконке и подписи, не жирная плашка на весь слот.  
Create по центру — плюс чуть крупнее (24), не «floating action button» поверх контента (FAB = чужой паттерн).

Desktop: шапка 64, текст 15 Medium, активный пункт — accent underline 2px, не таблетка LinkedIn.

---

## 15. Density (плотность)

Public: комфортное сканирование ~2 карточки на первый экран mobile (фото занимает ~180px высоты).  
Admin: строки ~72, меньше воздуха.

---

## 16. Mobile interaction principles

- Большой палец: таббар и sheet-кнопки внизу.
- Нет hover-only действий.
- Фильтры не на первом кадре полностью — кнопка «Фильтры».
- Клавиатура не автофокус на Поиске при входе на таб.
- Pressed: opacity 0.92 на карточке / кнопке, 80ms, без spring-bounce.

---

## 17. Что запрещено визуально

Градиенты бренда, стеклянный blur, dark theme в MVP, стоковые фото «улыбки мастеров» как паттерн пустых состояний, счётчики «сегодня 12», аватары в списке карточек.
