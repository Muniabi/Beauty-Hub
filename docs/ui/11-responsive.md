# 11 — Responsive (375 / 768 / 1280)

**UX:** [../ux/11-responsive-strategy.md](../ux/11-responsive-strategy.md)  
Mobile-first. Обязательные макеты: 375 и 1280. 768 — сетка 2 колонки + TabBar.

---

## 375

- Поля 16, карточки 343, фото 4:3.
- TabBar 4 слота, высота 56+safe, **Create по центру**, иконка 24, подпись 11.
- Одна рука: фильтры sheet снизу, кнопки sheet над индикатором.
- Search: чипы влезают без горизонтального скролла (3× ~108).
- Forms: одна колонка, input 48.
- Login: виджет не уже 280, не обрезать WebView — поля 16.
- Details: галерея full bleed 375, контент 16.

TabBar не перекрывает CTA: padding-bottom контента `56 + 8 + safe`.

---

## 768

- TabBar остаётся (решение U0/U1).
- Search список **2 колонки**, gap 12, поля 16–24.
- Home плитки ещё столбиком или 3 в ряд? **3 в ряд** на 768 (ширина позволяет), высота плитки 72.
- Формы max 560 по центру.
- Admin: compact rows ещё ок, таблица с 768+.

---

## 1280

- Header 64, без TabBar.
- Контент 1120 center.
- Search: FilterBar 240 + 2 колонки карточек.
- Home: hero + плитки 320 справа.
- Details: 640 галерея + 456 мета, CTA sticky.
- Admin: таблица очереди.
- Login: колонка 400 center.
- Create preview: форма 560 + превью карточки 428.

Hover только здесь (карточка borderStrong).
