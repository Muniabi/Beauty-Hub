# 02 — ListingCard (визуальная спецификация)

**UX:** [../ux/03-listing-card.md](../ux/03-listing-card.md)  
**Токены:** [01-ui-foundation.md](01-ui-foundation.md)

Один компонент, три типа: Space / Event / Vacancy. Различие — бейдж и строка акцента, не три макета.

Нет favorite. Нет featured. Нет автора в списке. Нет CTA в списке.

---

## 1. Общая анатомия (все типы)

```text
┌─────────────────────────────┐  radius.card, border.default, surface
│           IMAGE 4:3         │
├─────────────────────────────┤
│  pad 12                     │
│  [Бейдж]  район             │  caption
│  Заголовок 2 строки         │  cardTitle
│  Акцент (цена|дата|dir)     │  accentMeta
│  [спец] [спец] +N           │  badge 12
│  pad 12 bottom              │
└─────────────────────────────┘
```

Hit area: весь блок = ссылка. Pressed: opacity 0.92.

## 2. Mobile 375

**Ширина карточки:** 375 − 32 = **343** (поля экрана 16).  
**Зазор между карточками:** 12.

| Элемент | Правило |
| --- | --- |
| Image | ширина 343, высота **258** (4:3), object-fit cover, верхние углы 10 (клип), нижние у фото 0 |
| Нет фото | высота 258, `surfaceMuted`, по центру бейдж типа (не растягивать подпись) |
| Блок мета | padding 12; gap вертикаль 8 |
| Строка 1 | бейдж + точка или 8px gap + район `textMuted` caption, одна строка ellipsis |
| Заголовок | max 2 строки, ellipsis, color.text |
| Акцент | 1 строка, color.text (не accent — accent для кнопок; цена читается weight 700) |
| Спец. | чипы height 22, radius 6, max 2 + `+N` muted; gap 6; не переносить на 3-ю строку чипов — hide overflow |

**Высота карточки Space с фото ≈** 258 + 12 + 22 + 8 + 44 + 8 + 22 + 8 + 22 + 12 ≈ **416** (заголовок 2 строки). С 1 строкой заголовка ниже.

Сетка: 1 колонка.

---

## 3. Desktop 1280

Контент 1120. Фильтры слева 240 + gap 24 + сетка **2 колонки** карточек (ширина колонки ≈ 428) **или** фильтры сверху и **3 колонки** ≈ 357.

**Решение U1 (как UX):** фильтры слева на 1280 → **2 колонки**. 3 колонки — если FilterBar сверху на ширине >1440. Для макета 1280 рисовать **2 колонки**.

Карточка колонки ~428:

| Элемент | Правило |
| --- | --- |
| Image | ширина 100% колонки, 4:3 (≈ 428×321) |
| Мета | padding 16 (чуть больше mobile) |
| Hover | border `borderStrong`, cursor pointer, **без** translateY |
| Focus-visible | 2px accent ring offset 2 |

Та же вертикальная иерархия, что mobile. Не горизонтальный ряд.

## 4. Compact (не каталог)

Высота ряда **72**. Thumb 72×72 слева (4:3 crop center), radius 8. Справа: бейдж+StatusBadge в одну линию, title 1 строка, район caption. Для Profile «Мои» и Admin queue mobile.

---

## 5. Type badge

Единый стиль `surfaceMuted` + `text` + `type.badge`.

| type | Подпись |
| --- | --- |
| space | Кабинет |
| event | Мероприятие |
| vacancy | Вакансия |

Не цветные «скины» карточки. Не иконка без текста.

---

## 6. Metadata по типу

| Тип | Строка акцента (пример) |
| --- | --- |
| Space | `18 000 ₽ / месяц` |
| Event | `25 сен · 18:00` |
| Event бесплатно | `Бесплатно · 25 сен` |
| Vacancy | `Ищу мастера` / `Ищу работу` |

Район всегда во второй позиции строки 1, не в акценте.

---

## 7. Typography на карточке

- Badge: 12/16 Semibold  
- Район: 13/18 Medium muted  
- Title: 16/22 Semibold  
- Accent meta: 16/22 Bold  
- Spec chips: 12/16 Medium

## 8. States

| State | Визуал |
| --- | --- |
| normal | как выше |
| loading | Skeleton: блок 343×258 muted pulse + 3 полоски 12/16/24 высотой, radius 10, без текста |
| expired | в списке нет; см. details |
| pending/rejected | только compact + StatusBadge warning/danger |

Нет overlay «недоступно» в public list.
