# 09 — Profile (визуал)

**UX:** SCR-PROFILE, SCR-SETTINGS · DEC-12, DEC-16

На mobile Профиль = таб 4. Settings — либо секция ниже, либо `/settings` отдельный. **Решение U1:** один скролл Profile: шапка пользователя → Мои объявления → Уведомления → Выход; «Ещё» (удаление, legal) внизу. Отдельный `/settings` может дублировать уведомления для бота-ссылок — визуально тот же блок тогглов.

---

## 1. Mobile 375

### Шапка пользователя

Avatar 56 radius 8 (фото или инициалы на surfaceMuted).  
Имя `title` 20. Роль caption (Мастер / Салон или помещение / Организатор).  
Район caption если есть.  
Ссылка «Редактировать» 13 accent (поля онбординга).

### Мои объявления

Сегмент статусов: Все | На проверке | Отклонено | Опубликовано — height 36, скролл если не влезают.  
Список compact cards. Empty: «Пока нет объявлений» + secondary «Создать».

StatusBadge на compact обязателен.

### Уведомления Telegram

Заголовок 16 Semibold. Caption: «Сообщения о новых объявлениях выбранного типа. По умолчанию выключено.»  
Три ряда 56h: подпись слева, toggle справа (off = border track, on = accent).  
Кабинеты / Мероприятия / Вакансии.

### Сессия

«Выйти» secondary full width.  
«Удалить аккаунт» text danger 15, затем dialog confirm.

Legal ссылки caption.

---

## 2. Desktop

Две колонки: слева 320 профиль+тоглы sticky; справа список объявлений шире compact или карточки 1 колонки 560.

---

## 3. Гость на /profile

Не пустой профиль: редирект login `next=/profile` (как UX). Кадра «пустой аккаунт» нет.

---

## 4. Logout / delete dialogs

Dialog width 320, radius 10, elevation.dialog.  
Выйти: «Выйти?» Отмена / Выйти primary.  
Удалить: текст spec, Отмена / Удалить danger.
