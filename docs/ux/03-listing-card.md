# 03 — ListingCard (карточка объявления)

**Канон:** [../24-implementation-spec.md](../24-implementation-spec.md) §3.6 · [00 UX-DEC-02, 03, 06, 07](00-ux-blueprint.md)

Главный вопрос: **за 2–3 секунды понять тип, место и цену/дату и решить, открывать ли.**

---

## 1. Единый визуальный язык, не три UI

Один компонент `ListingCard` с вариантом `type`. Различие:

- бейдж типа (текст + форма, не только цвет);
- второй ряд метаданных (цена **или** дата **или** direction).

Не делать три несовместимых шаблона.

---

## 2. Иерархия (список)

Сверху вниз, mobile:

1. Фото (соотношение ~4:3, object-fit cover). Нет фото у Event/Vacancy — плашка с бейджем типа на нейтральном фоне.
2. Строка: бейдж типа · район.
3. Заголовок (2 строки max, ellipsis).
4. Акцент мета: цена+период / дата+время / direction.
5. Специализации: 1–2 чипа, далее `+N`.

**Нет в списке:** контакт, автор, описание, избранное, share, статус published (и так все published).

**Есть у автора в «Мои»:** StatusBadge pending/rejected/expired/archived.

---

## 3. Метаданные по типу

| Тип | Бейдж | Акцент | Дополнительно в списке |
| --- | --- | --- | --- |
| Space | Кабинет | `{price} ₽ / {месяц\|смена\|час}` | опц. м² не обязательны в списке |
| Event | Мероприятие | `{день} · {время}` | — |
| Vacancy | Вакансия | «Ищу мастера» или «Ищу работу» | — |

Цена Event «бесплатно» — слово «Бесплатно» вместо суммы.

---

## 4. Страница карточки (SCR-CARD)

Добавляется к иерархии списка:

- галерея (свайп), 1–6 фото;
- полное описание;
- все специализации;
- адрес текстом у Event если есть;
- площадь / вид места у Space если есть;
- capacity, external_url у Event;
- формат занятости у Vacancy;
- **блок автора:** display_name, роль-подпись, не телефон;
- **CTA контакт** (см. [05](05-auth-contact-flow.md));
- Жалоба (авторизован);
- у автора: ModerationBanner (pending/rejected+причина).

---

## 5. Варианты раскладки

### Mobile (список) — UX-DEC-07

Вертикальная карточка на всю ширину контента, одна колонка, отступ 16px. Вся карточка кликабельна (кроме будущих отдельных кнопок — их нет).

### Desktop (список)

Сетка 2 колонки (1024) / 3 (широко). Та же вертикальная структура, не горизонтальный «ряд Avito», чтобы не плодить два языка.

### Compact (админка, «Мои объявления»)

Слева thumb 72px, справа: бейдж+статус, заголовок, район, дата подачи. Не для публичного каталога.

### Featured

**Не делать** (UX-DEC-03).

---

## 6. CTA

| Контекст | CTA |
| --- | --- |
| Список | нет отдельной кнопки — тап по карточке |
| Страница, гость | «Войти, чтобы написать» |
| Страница, авторизован | «Написать в Telegram»; если phone — вторичная «Позвонить» |
| Event + external_url | вторичная «Регистрация» (external) рядом, не вместо контакта если контакт нужен |
| Expired / 404 | CTA нет или «К поиску» |

Избранного нет (UX-DEC-02).

---

## 7. Состояния

| Состояние | Список | Страница |
| --- | --- | --- |
| normal | published | полный контент |
| loading | SkeletonCard | скелетон галереи+текста |
| expired | не показывается | «Объявление неактуально» + к поиску |
| 404 / чужой draft | — | «Не найдено» |
| pending | только у автора compact + бейдж | баннер 24 часа, контакта публичного нет |
| rejected | у автора | баннер с причиной |
| moderated/hidden | нет в public GET | как 404 для гостя |

Отдельного «unavailable» кроме expired/404 нет.

## 8. Wireframe (mobile список)

```text
┌─────────────────────────┐
│         ФОТО            │
├─────────────────────────┤
│ [Кабинет]  Ворошиловский│
│ Кабинет 14 м² у Садовой │
│ 18 000 ₽ / месяц        │
│ [nail] [brow]           │
└─────────────────────────┘
```

Event: строка акцента `25 сен · 18:00`. Vacancy: `Ищу мастера`.

---

## 9. A11y карточки

- Бейдж текстом «Кабинет», не только цвет.
- Alt фото: «фото кабинета» или заголовок.
- Карточка в списке — одна ссылка на `/listings/:id`, без вложенных кнопок.
- Focus ring на desktop.
