# 01 — Information Architecture (информационная архитектура)

## 1. Карта продукта (не соцсеть)

```text
Beauty Hub (веб)
├── Главная                         /
├── Поиск (система записи каталога)
│     ├── Кабинеты                  /search?type=space   и /spaces
│     ├── Мероприятия               /search?type=event   и /events
│     └── Вакансии                  /search?type=vacancy и /jobs
├── Карточка                        /listings/:id
├── Создать
│     ├── тип                       /create
│     ├── кабинет                   /create/space
│     ├── мероприятие               /create/event
│     └── вакансия                  /create/vacancy
├── Вход                            /login?next=
├── Онбординг                       /onboarding/role|profile|notifications
├── Профиль                         /profile
├── Настройки                       /settings
├── Право                           /legal/privacy|terms
└── Админка (скрыта)                /admin/*
```

Нет: `/masters`, `/feed`, `/radar`, `/club`, `/learn`, inbox уведомлений.

---

## 2. Навигация mobile (заморожена)

Нижний таббар, 4 пункта, высота зоны ≥44px:

| Слот | Подпись | Маршрут | Гость |
| --- | --- | --- | --- |
| 1 левый | Главная | `/` | да |
| 2 | Поиск | `/search` (type=space если нет query) | да |
| 3 центр | Создать | `/create` | → `/login?next=/create` |
| 4 правый | Профиль | `/profile` | → `/login?next=/profile` |

На `/listings/:id` ни один таб не active. Назад — шеврон к предыдущему URL (сохранить query поиска).

---

## 3. Навигация desktop (≥1024)

Шапка:

`Логотип (→ Home) | Кабинеты | Мероприятия | Вакансии | Создать | Профиль или Войти`

Кабинеты / Мероприятия / Вакансии = пресеты Search, не отдельные деревья IA.

---

## 4. Иерархия «что важнее»

```text
Тип объявления
  → район
    → цена или дата
      → специализация
        → фото как доказательство
          → контакт (после входа, только на странице)
```

Home = ориентация. Search = работа.

---

## 5. Глубина кликов (цели)

| Задача | Клики с Home mobile |
| --- | --- |
| Список кабинетов | 1 |
| Открыть карточку | 2 |
| Промпт логина на контакте | 3 |
| Уже в сессии: открыть Telegram | 3 |

Create после онбординга: тип → форма → превью → отправка ≤ 4 шага.

---

## 6. URL и возврат

Один экран Search. Пресеты для шаринга. Query сохранять: `/search?type=space&district_id=...`. С карточки «Назад» возвращает к тому же списку.

`login?next=` — полный путь с query карточки.

---

## 7. Админка

`/admin` не в таббаре. Пункты: Очередь, Жалобы, Пользователи, Сводка. 403 для не-admin. Визуал утилитарный.
