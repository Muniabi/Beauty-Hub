# 07 — Create Listing (создание объявления)

**Канон:** §3.7 spec · DEC-08, DEC-21 · статусы §2.6

После создания карточка **не** попадает в public catalog до approve.

```text
Draft → Submitted/pending → Moderation → Published | Rejected
```

---

## 1. Доступ

Гость: `/login?next=/create`.  
Профиль не completed: онбординг, затем create.  
Любая роль может любой тип; подсветка дефолта: space_owner → Кабинет, organizer → Мероприятие, master — без подсветки (три равные).

---

## 2. SCR-CREATE-TYPE

Три крупные кнопки:

- Кабинет  
- Мероприятие  
- Вакансия  

Короткий hint под вакансией: «Ищу мастера или ищу работу — на следующем шаге».

Нет четвёртого типа.

---

## 3. Поля

Обязательные *. Валидация на клиенте + повтор на сервере. Сообщения под полем.

### Space

| Поле | Обяз. | Заметки |
| --- | --- | --- |
| Фото 1–6 | ≥1 | JPEG/PNG/WebP, ≤5 МБ, превью, удаление |
| Заголовок | * | до ~80 символов |
| Описание | * | |
| Район | * | select seed |
| Специализации | * ≥1 | мульти чипы |
| Цена | * | число |
| Период | * | месяц / смена / час |
| Площадь м² | нет | |
| Вид места | нет | кабинет / кресло / коворкинг / другое |
| Контакт | предзаполнен с профиля, можно править Telegram |

### Event

Заголовок*, описание*, дата-время начала* (не в прошлом), район*, специализации*, цена или чекбокс «Бесплатно»*, фото 0–6, адрес текст, capacity, external_url.

### Vacancy

Заголовок*, описание*, район*, специализации* мульти, direction* (Ищу мастера / Ищу работу), формат аренда/найм/процент/другое, фото опц.

Подсказка района: «ЗЖМ обычно Советский, Северный — Первомайский».

---

## 4. Черновик

Кнопка «Сохранить черновик» — без всех обязательных можно, минимум заголовок или пустой draft. Не уводить в модерацию.

---

## 5. Preview

Показ как публичная карточка (гость-вид, без контакта или с «так увидят в поиске»). CTA «Отправить на проверку». Назад — форма с данными.

---

## 6. Submit → Pending

SCR-PENDING-OK: «На проверке. Обычно в течение 24 часов.» Кнопки: «Мои объявления», «На главную».

---

## 7. Редактирование

Черновик/rejected: форма снова.  
Pending: редактирование можно (сбрасывает? **Решение:** правки pending остаются pending).  
Published: сохранение → снова pending, баннер «Снова на проверке, пока не в каталоге» (DEC-21).  
Expired: «Создать заново» или продление нет в MVP — только архив + новое. **Решение:** expired — просмотр, кнопка «Скопировать в новое» не делать (лишнее). Архив.

---

## 8. Rejection

В «Мои»: бейдж + причина. CTA «Исправить и отправить».

---

## 9. Состояния формы

Loading upload (прогресс на превью фото), error типа файла, error сети submit, validation. Success = pending screen.

Unauthorized на /create → login.

---

## 10. Mobile

Одна колонка. Sticky низ: «Далее» / «Отправить». Фото — горизонтальный ряд превью + add. Дата event — нативный date/time picker.

Не wizard из 8 шагов: **один скролл формы** + preview.
