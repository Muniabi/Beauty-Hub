# 11 — Responsive strategy (адаптив) и a11y

Mobile-first: сначала 375, затем 768, затем 1280.

---

## 1. Брейкпоинты

| Имя | Ширина | Навигация | Каталог |
| --- | --- | --- | --- |
| mobile | 375–767 | TabBar низ | 1 колонка карточек |
| tablet | 768–1023 | TabBar **или** верхние вкладки — **решение: TabBar**, карточки 2 колонки | |
| desktop | ≥1024 | Header | 2–3 колонки, фильтры слева/сверху |

Обязательные макеты UI-этапа: **375** и **1280**. 768 желателен (сетка 2).

---

## 2. Одна рука (mobile)

- Таббар закреплён снизу, Create по **центру** (большой палец).
- Фильтры — sheet снизу, кнопки Сбросить/Показать в безопасной зоне над таббаром sheet (sheet закрывает таббар).
- CTA контакта на карточке — sticky низ страницы над таббаром **или** в потоке после описания. **Решение:** CTA **в потоке после мета**, плюс дубль sticky только если описание длинное > viewport. Проще MVP: **один CTA в потоке**, не два. Длинное описание — пользователь доскроллит; для MVP ок.
- Не прятать поиск за hamburger на mobile.

---

## 3. Touch

Минимум 44×44 CSS px для таббара, чипов, кнопок, закрытия sheet.

---

## 4. Карточка и сетка

Mobile: full width. Tablet: 2. Desktop: 2 при фильтрах слева, 3 если фильтры сверху на широком.

---

## 5. Админка

Desktop-first допустим (таблица). Mobile compact-очередь всё же описан в [08](08-moderation.md) — модератор со смартфона в бете.

---

## 6. Accessibility (минимум WCAG AA)

| Тема | Правило |
| --- | --- |
| Keyboard | desktop: Tab по чипам, карточкам-ссылкам, кнопкам; Enter активирует |
| Focus | видимое кольцо, не outline:none без замены |
| Labels | у каждого input видимый label |
| Contrast | body 4.5:1; бейдж типа не только цветом |
| Touch | 44px |
| Errors | текст, не только красная рамка |
| Images | alt |
| Login | виджет Telegram — не ломать порядок фокуса страницы |
| Reduced motion | без обязательных анимаций смысла |

Не цель: полная сертификация, screen-reader audit каждого админ-фильтра в U0.

---

## 7. Контент на узком экране

Заголовки карточек 2 строки. Цена не переносится отдельно от периода. Чипы специализаций не раздувают карточку >2 +N.
