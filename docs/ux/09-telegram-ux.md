# 09 — Telegram UX

**Канон:** ADR-003, DEC-12, DEC-13, DEC-16 · не второй клиент.

Telegram: уведомления, канал, механизм контакта (`t.me`).  
Не Mini App, не CRUD бота, не поиск в боте.

---

## 1. Роли поверхностей

| Поверхность | Задача |
| --- | --- |
| Login Widget | вход на сайте |
| Бот DM | opt-in сообщения о новых published своего типа |
| Канал | витрина для тех, кто не логинился |
| t.me ссылка | контакт автора |

---

## 2. Команды бота

| Команда | Поведение |
| --- | --- |
| `/start` | «Это бот Beauty Hub. Объявления и поиск — на сайте. Здесь — уведомления.» Кнопки: Открыть сайт, Настройки |
| `/settings` | три тогла Кабинеты / Мероприятия / Вакансии (синхрон с сайтом) |
| `/help` | ссылка на сайт + что не умеет бот |
| `/stop` | все тоглы false, «Выключено. Включить: /settings» |

Любой свободный текст: «Создать объявление и искать удобнее на сайте: {url}». Не парсить «сдам кабинет».

---

## 3. Opt-in

По умолчанию все false. Онбординг сайта предлагает включить, skip можно. Бот не спамит до включения.

---

## 4. Шаблон DM

```text
Новое объявление · {Кабинет|Мероприятие|Вакансия}
{title}
{district} · {price или date}

[ Открыть карточку ]
```

URL: `{origin}/listings/{id}?utm_source=telegram&utm_medium=dm`

Один listing — одно DM (дедуп). Автор не получает своё.

---

## 5. Шаблон канала

То же + шапка «Beauty Hub Ростов». Пост только после approve. Исторические посты не редактировать при expire.

---

## 6. Deep link с канала/DM

Открывается сайт (мобильный браузер). Пользователь может быть гостем — карточка публичная, контакт через login next.

---

## 7. Настройки на сайте vs бот

Источник правды — `/settings`. Бот дублирует тоглы. Расхождение не допускается продуктово (один API).

---

## 8. Что не проектировать

Клавиатуры «выберите район» для поиска, мастера создания, Mini App, rich меню как у интернет-магазина.
