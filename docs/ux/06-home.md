# 06 — Home (главная)

**Канон:** DEC-11 — не Radar · [00](00-ux-blueprint.md)

Вопрос экрана: **что полезного я могу найти здесь прямо сейчас?** Ответ: три типа профессиональных объявлений Ростова и переход в Search.

Не dashboard, не лента, не «сегодня в городе» с нулями.

---

## 1. Структура mobile (сверху вниз)

1. Шапка: словомарка «Beauty Hub», опционально «Ростов-на-Дону» muted. Справа не дублировать Войти — таб Профиль.
2. **Hero (короткий):** заголовок + одна строка подзаголовка.
   - Заголовок: «Кабинеты, мастер-классы и вакансии для мастеров Ростова»
   - Подзаголовок: «Без чатов, в которых всё тонет»
3. **Три плитки-входа** (primary): Кабинеты · Мероприятия · Вакансии. Каждая ведёт в Search с type. Крупные, на всю ширину или 1+2 не делать — **три равные плитки столбиком** (большой палец, одна колонка).
4. **Блок «Новые»** только если есть ≥1 published: заголовок «Недавно» + до 6 карточек смешанных? **Нет:** DEC и сканирование. **Решение:** блок «Новые кабинеты» если type=space есть, иначе не показывать смешанное. Ещё проще: **три мини-ряда по 2 карточки** перегрузят.

**Решение U0:** один блок «Новые объявления» **только одного типа — кабинеты** (дефолтный спрос), ссылка «Все кабинеты». Если кабинетов 0, но есть события — блок «Ближайшие мероприятия». Если пусто всё — не блок, а empty hero CTA.

Приоритет блока:

```text
есть space → Новые кабинеты (до 4 карточек)
иначе есть event → Ближайшие мероприятия (до 4)
иначе есть vacancy → Свежие вакансии (до 4)
иначе empty seed
```

Не три секции сразу (перегруз).

5. Таббар.

Desktop: hero слева/сверху, три плитки в ряд, затем сетка «Новые».

---

## 2. Empty seed

Текст spec: «Пока собираем объявления Ростова. Если сдаёте кабинет или проводите мастер-класс — добавьте карточку.»

CTA: Создать (гость → login next=/create). Вторичных «оставить Telegram» форм нет (второй продукт).

Не скелетоны фейковых карточек.

---

## 3. Состояния

| State | UI |
| --- | --- |
| Loading | скелетон плиткок + 2 skeleton cards |
| Empty | copy + Создать |
| Error | баннер повтор |
| Success с данными | плитки + блок новые |
| Unauthorized | не нужен |

---

## 4. Чего нет

Счётчики «сегодня 12», stories, карусель онбординга, поиск на главной отдельным большим полем (плитки достаточно; дубль q на Home — нет, чтобы не плодить два поиска).

`DECISION REQUIRED` слабый: поисковая строка на Home. **Предложение:** нет, плитки сильнее для трёх типов.

---

## 5. Primary path

Home → плитка Кабинеты → Search → Card → Contact. Hero не конкурирует с плитками: плитки — главный CTA.
